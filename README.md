# 🎵 Moodify

A modern and responsive music player built with **React.js** that provides a smooth music listening experience with an intuitive and clean user interface.

## ✨ Features

- 🎧 Play, Pause, Next & Previous Controls
- 🔊 Volume Control
- 📜 Dynamic Playlist
- 🎵 Currently Playing Song
- 📱 Fully Responsive Design
- ⚡ Fast & Lightweight
- 🎨 Clean and Modern UI

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
